Privacidad y límites

No se publican registros individuales de accidentes ni coordenadas de eventos (F05). Las solicitudes 311 tampoco se muestran a nivel de caso. Las fuentes con licencia «no declara» no se presentan como si tuvieran una licencia abierta explícita.

Herramientas

Visualización elegida para este prototipo: Leaflet (licencia BSD-2-Clause), con cartografía desde NYC Open Data. La comparación con una segunda herramienta queda pendiente de ejecución verificable; no se declara una prueba que no ocurrió.
